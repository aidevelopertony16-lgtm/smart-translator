# 🌐 Smart Translator | المترجم الذكي

An intelligent Arabic-to-English translator built using Python and Google's Gemini AI API. 
مترجم ذكي تفاعلي للترجمة من العربية إلى الإنجليزية، مبني باستخدام لغة بايثون ونموذج جيميناي من جوجل.

## 🚀 Features | المميزات
* **Real-time Translation:** Translates text instantly. (ترجمة فورية للنصوص).
* **Arabic Support:** Fully supports Arabic characters (دعم كامل للحروف العربية).
* **Secure:** Uses environment variables to protect API keys (يستخدم متغيرات بيئة لحماية مفاتيح API).

## 🛠️ Tech Stack | التقنيات المستخدمة
* Python
* Google Colab
* Gemini API (Google GenAI)
